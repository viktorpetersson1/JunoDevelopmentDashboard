# T013 — CI workflow

**Goal:** GitHub Actions runs lint + typecheck + unit + integration + golden + build on every PR touching `atlas/**`. Matches the bundle's "5 jobs" spec (with integration + golden as stubs until their dependencies land).

## What changed

### Modified

- `atlas/.github/workflows/ci.yml` — added `integration` and `golden` stub jobs. The two stubs always pass with a `deferred-to-ticket` message so they can be marked as required GitHub checks from day one without blocking merges. They replace themselves with real assertions when:
  - `integration` → T076 (production deploy provisions a CI-accessible Supabase test branch)
  - `golden` → T032′–T034′ (calc engine port; snapshots against `public/engine.js`, NOT Excel — see SUPABASE_TRANSLATION.md §2)
- `atlas/README.md` — new "CI" section documents all 6 jobs + the one-time GitHub UI step to mark them required.
- `atlas/lib/__tests__/tokens.test.ts` — assertions made case-insensitive + whitespace-tolerant. Prettier normalised hex values (`#FFFFFF` → `#ffffff`) and collapsed multi-space in `cubic-bezier(...)`. CSS is case-insensitive for hex; semantics are unchanged.

### Prettier sweep

Ran `pnpm format --write` across all 75 source files to normalise to project Prettier rules. The diff is whitespace + hex-case only. All tests still pass (187/187 after the token test update). `pnpm format:check` now passes — required by the `lint` CI job.

## Deviations from bundle (logged)

- **6 jobs instead of 5** — split `typecheck` out from `lint` so a typo doesn't fail both. Otherwise matches the bundle list (lint, unit, integration, golden, build).
- **`integration` + `golden` are stubs** — wired with `echo + exit 0` until their underlying work exists. Marking them required from day one means no GitHub workflow re-configuration when they fill in.
- **No `e2e` job** — Playwright is in the stack (per CLAUDE.md §4) but no specs exist yet (J1, J3, etc. land in T046+). Added later as a 7th CI job.
